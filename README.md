Готовые примеры работы с **API генератора тестовых данных РФ** на шести языках: **Python, TypeScript (Node.js), Go, Java, C#, PHP.**
Вымышленные, но формально корректные российские реквизиты для тестов и демостендов: **ФИО**, **ИНН физлица и юрлица**, **СНИЛС**, **ОГРН и ОГРНИП**, **КПП**, **расчётный счёт, согласованный со своим БИК**, паспорт, телефон, адрес, **номер банковской карты**, VIN. **Все контрольные суммы сходятся** — сгенерированный ИНН пройдёт проверку контрольного разряда, карта пройдёт по алгоритму Луна.

Каждый пример **запускается сразу — без регистрации, без ключа, без карты.** В коде зашит публичный демо-ключ.

```bash
git clone https://github.com/atlorium-api/test-data-generator-api-client
cd test-data-generator-api-client/python && pip install -r requirements.txt && python main.py
```

## Зачем это нужно

Наполнить демостенд, прогнать приёмные формы, собрать фикстуры для автотестов, показать заказчику работающий интерфейс до появления реальных данных, проверить импорт CSV на сотне строк.

Зарубежные генераторы тестовых данных выдают «российские» реквизиты случайными цифрами: такой ИНН не проходит проверку контрольного разряда, а счёт не сходится со своим БИК. Тестовые данные, которые ваша же валидация отвергает, бесполезны ровно там, где нужны.

Примеры не просто печатают JSON, а **применяют данные**: в каждом есть функция `verifyRecord()`, которая **независимо пересчитывает контрольные суммы** каждого выданного реквизита — ИНН физлица и юрлица, СНИЛС, ОГРН, расчётный счёт вместе с БИК и номер карты по алгоритму Луна. Это одновременно проверка обещания сервиса и готовые валидаторы, которые в проекте всё равно пришлось бы написать: копируйте их себе.

## Быстрый старт за 60 секунд

Проверить API вообще без клонирования:

```bash
curl -H "Authorization: Bearer ak_sandbox_demo_mockdata_v1" \
     "https://atlorium.com/api/testdata?count=1&fields=fullName,innPerson,snils"
```

| Язык | Запуск | Требуется |
|------|--------|-----------|
| [Python](python/) | `pip install -r requirements.txt && python main.py` | Python 3.10+ |
| [TypeScript / Node.js](node/) | `npm install && npm start` | Node.js 20+ |
| [Go](go/) | `go run .` | Go 1.22+ |
| [Java](java/) | `java Main.java` | JDK 11+ (без зависимостей) |
| [C#](csharp/) | `dotnet run` | .NET 8+ |
| [PHP](php/) | `php main.php` | PHP 8.1+ |

Запросить больше записей: `python main.py 10`

## Аутентификация

Ключ передаётся в заголовке `Authorization`:

```
Authorization: Bearer ВАШ_КЛЮЧ
```

| Ключ | Что делает |
|------|------------|
| `ak_sandbox_demo_mockdata_v1` | **Демо-ключ.** Публичный, один на всех. Денег не списывает, регистрации не требует. Отдаёт настоящий результат работы сервиса: моков здесь нет и быть не может |
| Боевой ключ | То же самое, но со счёта. Отличие в лимитах одно: они считаются по вашему ключу, а не по публичному IP, общему для всех, кто пробует демо. Получить в личном кабинете: [atlorium.com](https://atlorium.com) |

Переход на боевой ключ **не требует правок в коде** — все примеры читают переменную окружения:

```bash
export ATLORIUM_API_KEY="ak_ваш_боевой_ключ"
```

## Эндпоинты

Базовый адрес: `https://atlorium.com`

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET` | `/api/testdata` | Генерация параметрами строки запроса |
| `POST` | `/api/testdata` | То же самое телом JSON — удобно, когда полей много |
| `GET` | `/api/testdata/fields` | Справочник доступных полей. **Бесплатно** |

### `GET /api/testdata`

| Параметр | Тип | Описание |
|----------|-----|----------|
| `count` | int | Сколько записей: от 1 до 100. По умолчанию 1. **Это же число — стоимость запроса** |
| `fields` | string | Список полей через запятую: `fullName,innPerson,snils`. По умолчанию — ФИО, пол, дата рождения, ИНН физлица, СНИЛС, телефон, почта, адрес |
| `seed` | int | Начальное значение генератора. Одинаковый seed при одинаковых остальных параметрах даёт **в точности одинаковый результат** |
| `gender` | string | `any` (по умолчанию), `male` или `female` |
| `format` | string | `json` (по умолчанию) или `csv` |

### `POST /api/testdata`

```json
{
  "count": 10,
  "fields": ["fullName", "innPerson", "snils", "bic", "bankAccount"],
  "seed": 20260823,
  "gender": "female",
  "format": "json"
}
```

Тот же контракт, что у `GET`, — только `fields` передаётся массивом, а не строкой.

### `GET /api/testdata/fields`

Возвращает справочник: идентификатор поля, человеческое название, группу, признак наличия контрольной суммы и пример значения. Идентификаторы отсюда идут в параметр `fields`. Запрос **бесплатный**: справочник описывает контракт, а не результат работы сервиса. Слот rate-limit он при этом занимает, как любой другой вызов.

## Доступные поля

30 полей, восемь групп. Столбец «КС» отмечает поля, у которых есть контрольная сумма.

| Группа | Поля | КС |
|--------|------|----|
| Персона | `lastName`, `firstName`, `middleName`, `fullName`, `gender`, `birthDate` | — |
| Налоговые реквизиты | `innPerson` (12 цифр), `innCompany` (10 цифр), `ogrn` (13), `ogrnip` (15) | да |
| Налоговые реквизиты | `kpp` | — |
| Документы | `snils` | да |
| Документы | `passport` (серия с кодом региона и номер) | — |
| Банк | `bankAccount`, `correspondentAccount`, `cardNumber` | да |
| Банк | `bic`, `bankName`, `cardBrand`, `cardExpiry` | — |
| Контакты | `phone`, `email`, `login` | — |
| Адрес | `address`, `region`, `city`, `postalCode` | — |
| Организация | `companyName` | — |
| Транспорт | `vin` | да |
| Транспорт | `vehiclePlate` | — |

Все поля записи согласованы между собой: ФИО соответствует полу, e-mail и логин строятся из ФИО, расчётный счёт сходится с БИК той же записи, КПП начинается с кода региона из ИНН юрлица.

Точный, всегда актуальный список — `GET /api/testdata/fields`.

## Поля ответа

| Поле | Тип | Что содержит |
|------|-----|--------------|
| `seed` | int | **Фактически использованное** начальное значение. Если вы его не задали, сервис выбрал сам — сохраните, чтобы повторить выдачу |
| `count` | int | Сколько записей вернулось |
| `fields` | string[] | Поля в каноническом порядке. Он может отличаться от порядка в вашем запросе |
| `records` | array | Записи: объект «имя поля → значение», все значения строковые |
| `disclaimer` | string | Напоминание о вымышленности данных. Показывайте его там, где выдачу увидит человек |

В формате CSV возвращается плоская таблица со строкой заголовков, а использованный seed приходит **заголовком ответа `X-Atlorium-Seed`** — у таблицы нет места под метаданные. Заголовок ставится в обоих форматах, поэтому разбирать ответ по-разному не приходится.

## Обработка ошибок

| Код | Причина | Что делать |
|-----|---------|------------|
| `400` | Количество записей вне диапазона 1–100, неизвестное имя поля или неизвестный формат | Сверьтесь со справочником `/api/testdata/fields` |
| `401` | Ключ отсутствует, просрочен или недействителен | Проверьте заголовок `Authorization` |
| `402` | Недостаточно кредитов на балансе | Пополнить на [atlorium.com](https://atlorium.com) |
| `429` | Превышен rate-limit | Повторить с задержкой |
| `503` | Сервис временно недоступен: плановые работы | Повторить позже; в `message` — ссылка на страницу статуса [atlorium.com/status](https://atlorium.com/status). **Запрос не тарифицируется** |

Кода `404` у этого сервиса нет, а `503` бывает только на время плановых работ на платформе. Сам генератор **полностью локальный** — ни одного исходящего вызова, ни одного обращения к базе. Падать ему нечему, искать нечего, а единственный сценарий ошибки по вашей стороне — некорректный запрос, который отбраковывается до списания кредитов.

Во всех шести примерах коды разложены в человекочитаемые причины — смотрите класс `AtloriumError`.

## Цены и лимиты

Оплата **pay-as-you-go, без подписки**. Единица работы здесь — **одна запись, а не один вызов**: запрос на сто записей стоит сто единиц. Так и задумано — иначе клиент, забирающий данные пачками по сто, ездил бы за счёт того, кто берёт их по одной.

Справочник полей бесплатен. Актуальные цены и лимиты — на **[atlorium.com/pricing](https://atlorium.com/pricing)**.

## Частые вопросы

**Как сгенерировать тестовый ИНН, который пройдёт валидацию?** Запросить поле `innPerson` (физлицо, 12 цифр) или `innCompany` (юрлицо, 10 цифр). Контрольные разряды считаются по официальному алгоритму — примеры в этом репозитории пересчитывают их независимо и показывают результат.

**Чем это лучше обычного фейкера?** Библиотеки-генераторы делают правдоподобные строки, но не считают контрольные суммы российских реквизитов: их ИНН отвергнет ваша же форма, а счёт не сойдётся с БИК. Здесь сходится всё, включая связку «расчётный счёт ↔ БИК», которую нельзя получить, генерируя поля независимо друг от друга.

**Как получить одни и те же данные в каждом прогоне теста?** Передавайте `seed`. Одинаковый seed при одинаковых `count`, `fields` и `gender` даёт побайтово одинаковый результат — на этом строятся стабильные автотесты. Примеры проверяют это повторным запросом.

**Можно ли выгрузить данные в CSV?** Да, `format=csv`. Придёт плоская таблица со строкой заголовков; использованный seed — в заголовке ответа `X-Atlorium-Seed`.

**Сколько записей можно получить за один запрос?** До 100. Больше — несколькими вызовами; помните, что тарификация идёт по записям, а не по вызовам.

**Это персональные данные?** Нет. Все значения выдуманы генератором, никакой человек за ними не стоит, реестры не запрашиваются. Совпадение с реальными людьми и организациями случайно — и именно поэтому такие данные и годятся для демостендов, куда настоящие персональные данные класть нельзя.

**Можно ли использовать эти реквизиты в документах?** Нет. Данные предназначены только для тестирования. Использование для введения кого-либо в заблуждение, подделки документов или обхода проверок недопустимо.

- [Стандартизация адреса](https://github.com/atlorium-api/address-standardization-api-client) — разбор адресной строки на уровни
- [Аудит сайта](https://github.com/atlorium-api/core-web-vitals-api-client) — гейт релиза по Core Web Vitals и скорости загрузки страницы
